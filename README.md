# Book Tracker (Трекер прочитанных книг)

**Автор:** Васина Анастасия

## Описание
Графическое приложение для учёта прочитанных книг. Позволяет добавлять книги (название, автор, жанр, количество страниц), фильтровать по жанру и по минимальному числу страниц. Все данные сохраняются в файл `books.json` и автоматически загружаются при запуске.

## Требования
- Python 3.6+
- Стандартные библиотеки: tkinter, json, os (входят в поставку Python)

## Примеры использования

- **Позитивный тест:**  
  Название: "Мастер и Маргарита", Автор: "Булгаков", Жанр: "Роман", Страниц: 480 → книга появляется в таблице.

- **Негативный тест (пустое поле):**  
  Оставить поле "Название" пустым → сообщение "Заполните название и автора".

- **Негативный тест (страницы буквами):**  
  Ввести "abc" → ошибка "Количество страниц должно быть целым положительным числом".

- **Граничный тест (страниц = 0):**  
  Ввести 0 → ошибка (положительное число).

- **Фильтр по жанру:** выбрать "Детектив" → показываются только детективы.

- **Фильтр по страницам:** в поле "Страниц больше:" ввести 300 → отобразятся книги с числом страниц > 300.
